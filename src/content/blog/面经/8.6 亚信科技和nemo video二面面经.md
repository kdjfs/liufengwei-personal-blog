## 亚信科技 一面面经

本次面试完整面经汇总

一、基础信息开场

面试官告知本次考察前端基础知识，让我结合项目实战作答。

二、前端基础提问

1. JS 有哪些数据类型，以及如何判断数据类型？
2. 数组 map、filter、reduce 三个方法各自作用？
3. Vue2、Vue3 组件通信有哪些方式？
4. Vue2 和 Vue3 响应式原理实现方式及二者区别？
5. 元素水平垂直居中的实现方案有哪些？
6. SSE 流式接口前端调用方式与应用场景？

三、项目深挖提问

1. 星途智旅TripStar AI项目是否独立开发？
2. 该项目中ECharts知识图谱详细实现介绍？
3. 另外两个项目（万福鉴酒小程序、生猪智慧医药系统）是否独立从零开发？
4. 开发项目过程中是否使用Codex、Claude Code等AI编程工具，如何使用？

四、双向沟通环节

1. 面试结束后我向面试官提问：团队技术栈、岗位工作内容、新人带教、后续面试流程；
2. 面试官补充业务技术细节：团队图谱使用AntV G6、D3.js实现，和我ECharts图谱实现有区别；
3. 面试官介绍团队配置：前端共3人，加班极少，开年至今仅3次临时加班；
4. 面试官说明岗位性质：正式岗为外包，实习不属于外包。

五、面试整体总结

1. 考察方向：JS基础、Vue核心原理、CSS布局、流式通信、可视化图谱、真实项目落地经验、AI工具开发使用；
2. 项目重点：重点深挖个人独立开源项目，关注架构设计、性能优化、可视化实现、前后端分工；
3. 团队情况：3人前端小组，迭代压力小、加班少，业务包含图谱可视化、AI大模型相关需求；
4. 岗位区分：正式外包岗，实习为内部岗位。





腾讯会议总结

本次面试为一场技术岗的面试，面试官主要考察了候选人的JS基础、Vue框架知识及项目经验。
小结
1. 技术基础问答

JS数据类型: 候选人介绍了JS的基本数据类型（undefined, null, boolean, string, symbol）和引用数据类型（object），并提及了typeof、instanceof等判断方法。
数组方法: 解释了map（遍历返回新数组）、filter（筛选符合条件的元素）、reduce（累加迭代）三个方法的区别和用途。
Vue组件通信: 回顾了父子组件间的props和$emit、跨层级的provide/inject、全局状态管理（Vuex/Pinia）以及localStorage等本地存储方案。
Vue响应式原理: 指出Vue2使用Object.defineProperty实现，存在对数组和新增属性监听不足的问题；而Vue3采用Proxy全局代理，能更全面地监听对象和数组的变化。
元素居中方案: 提到了flex布局、absolute定位结合transform、margin auto等多种实现垂直水平居中的常用方法。
SSE接口: 解释了SSE是一种服务器推送技术，前端通过EventSource建立长连接，可实现断线重连的消息推送，适用于实时更新场景。

2. 项目经验介绍

"新图之旅"项目: 作为与后端共同开发的项目，候选人介绍了其功能：用户输入目的地、天数等信息，AI将生成个性化的旅游行程规划。
"智慧生猪医药系统": 作为与后端共同开发的项目，候选人主要负责前端，项目包含AI兽医智能对话等功能。

3. AI工具使用情况

候选人提到自己使用过多种AI工具辅助开发，包括GitHub Copilot、CodeX、DeepSeek等。

4. 公司信息了解

团队规模: 开发团队约20人，前端有3人。
加班情况: 团队加班较少，近一年仅三次。
