# 二、各问题精简核心答案

## （一）基础情况 & 实习时间

### 1. 在校 & 实习时长

大三，大一大二修满课程，仅周三全天有课；周一、二、四、五、周末可全天实习，一周可出勤 6 天。

### 2. 自我介绍要点

27 届应用数学本科；掌握 HTML/CSS/JS/ES6/TS 基础，Vue3 全家桶、Pinia、uni-app；

项目 1：鉴酒三端小程序，RBAC 多角色、短轮询 IM、分包首屏优化；

项目 2：生猪健康管理，ECharts 图表监控、AI 问诊、包体积压缩；

懂 Vite/Webpack 基础配置，Git 协作，骨架屏 / 图片懒加载等性能优化。

### 3. 项目独立开发

鉴酒项目为后端同学实验室项目，前端由我一人独立完整开发，负责页面、接口、权限、聊天、优化全部模块。

### 4. 项目搭建 + 难点解决

搭建：uni-app+HBuilderX 做小程序；Vite+VSCode 搭建 Vue 后台；先封装通用请求，按 UI 稿逐页面开发。

难点 1：多角色权限代码冗余

方案：RBAC 三层（用户 - 角色 - 权限），Pinia 存角色，封装权限 Hook，路由 meta 鉴权，动态 Tab 导航。

难点 2：轮询全量拉取消息，服务器压力大

方案：增量轮询，携带最新消息 ID，后端只返回新增数据；本地缓存历史消息合并，降低请求体积。

## （二）IM 聊天记录持久化

### 1. 重启保留历史记录

1. 聊天记录永久存入后端数据库；
2. 本地缓存本次会话消息，打开页面先读本地缓存，再增量拉取后端新数据合并；
3. Pinia 持久化存储登录角色身份，不会丢失登录态。

### 2. 切换用户数据隔离

聊天绑定唯一订单 ID + 用户 ID，切换账号后接口按当前用户 ID 筛选专属会话；气泡布局随登录角色左右区分展示，不同用户数据完全隔离。

## （三）Class 与面向对象

### 1. Class、面向对象理解

1. 面向对象三大特性：封装、继承、多态；
2. ES6 Class 是原型链的语法糖，底层仍是构造函数 + 原型；
3. 包含 constructor 构造器、实例方法、static 静态方法、extends 继承。

### 2. Class 继承适用场景

多角色存在通用逻辑（登录校验、权限判断），提取父类封装公共方法；用户 / 鉴定师 / 合作商作为子类继承，各自扩展独有业务，减少重复代码，方便统一维护。

## （四）购物车实时价格计算

1. 购物车数据存入 Pinia，数组存储商品 id、数量、单价、选中状态；
2. 使用 Pinia getters / 组件 computed 计算属性；
3. 依赖商品数组自动监听勾选、数量变更，实时汇总选中商品总价，无需手动调用计算函数。

## （五）uni-app 多端分辨率适配

1. rpx 相对单位：统一 750rpx 为屏幕满宽，自动换算不同设备像素；
2. Flex/Grid 弹性布局自适应；
3. 条件编译区分小程序 / H5/App，处理差异化样式；
4. 避免固定 px，全部使用弹性单位。

## （六）通用商品组件封装

### 1. 简略 / 详情差异化展示

1. 抽通用基础组件 GoodBase，统一商品基础渲染；
2. props 传参控制详情字段显隐；
3. 默认插槽展示详情专属图文，作用域插槽暴露商品数据，供父组件自定义操作按钮；
4. props 校验统一数据格式，避免渲染报错。

### 2. 子组件数量修改跨组件通信

1. 子组件点击加减，$emit 自定义事件，携带商品 id、新数量；
2. 父组件监听事件，调用 Pinia action 统一修改购物车全局状态。
