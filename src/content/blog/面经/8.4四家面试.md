2、简述一下src与href的区别

```
href是建立联系，src是把资源拿进来嵌入页面
href 建立资源链接关系，用a、link 浏览器不会下载嵌入资源，只是标记地址
src ： 引入、嵌入资源，用script，img，iframe ，浏览器会把资源下载并嵌入到当前文档，阻塞页面解析
```

7、js编程：给定一个整数数组nums，和一个目标值target，请你在该数组中找出和为目标值的两个整数，并返回他们的数组下标

示例：给定 nums = [7,11,2,15,...] ,target = 9

因为 nums[0] + nums[2] = 7 + 2 = 9 。所以返回[0,2]

```js
function fn(nums,target){
    for(let i = 0 ;i<nums.length ; i++){
        for(let j = i+1;j<nums.length;j++){
            if(nums[i] + nums[j] === target)  return [i,j]
        }
    }

}
```

8、说说你对promise的理解

promise是用来解决then链式调用回调地狱的，是用同步代码的编写方式编写异步代码，有async、await的语法糖

追问：什么时候用await

补充：

```
promise 是ES6 引入的处理异步的对象，用来解决回调地狱
有三种状态 pending，fulfilled，rejected，状态只能由pending到fulfilled/rejected，一经变化就不可在更改
示例方法 .then 处理成功 .catch 捕获失败 .finally 不管成功还是失败最好都会执行
通过.then链式调用，处理多层异步回调

await什么时候用
await 一般是在async后面用，只能写在async修饰的函数内部
它会暂停async函数的执行，等待promise状态完成，拿到成功结果再往下执行
```

9、举例你知道的http响应码及含义

```
200 请求成功 300重定向/协商缓存  400 客户端接口报错  500 服务器错误
200请求成功
201请求成功，并返回新资源
301永久重定向
302临时重定向
304 协商缓存  协商缓存命中为304  没命中为200
401 未认证或token失效
403 已认证，但无权访问该资源
404 资源被删除或失效
500 服务器内部代码错误
502 网关/代理服务器无法连接后端
503 （服务器宕机、维护中） 服务器暂时不可用
```
