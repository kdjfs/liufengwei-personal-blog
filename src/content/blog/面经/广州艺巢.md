## （二）JS 基础

### 1. this 作用与调用方式

- 作用：指向函数执行上下文对象；
- 四种调用：普通函数、对象方法、构造函数、call/apply/bind 绑定。

### 2. 闭包

1. 定义：内层函数引用外层函数变量，形成作用域保留；
2. 场景：私有变量、防抖节流、数据缓存；
3. 弊端：变量无法 GC，易内存泄漏。

### 3. 原型链

每个对象有__proto__指向构造函数 prototype；属性查找逐层向上查找，顶端 Object.prototype.__proto__为 null。

### 4. Promise & async/await

1. Promise 解决回调地狱，三种状态 pending/fulfilled/rejected；
2. async/await 是 Promise 语法糖，同步写法写异步；搭配 try/catch 捕获异常。

### 5. 数组排序

1. 基础升序：`arr.sort((a,b)=>a-b)`；
2. 手写冒泡：双层循环相邻对比交换，复杂度 O (n²)；
3. 优化：快速排序、归并排序，时间复杂度 O (nlogn)。

### 6. 快速排序核心思路

取基准值，数组分大于 / 小于基准两部分，递归左右子数组拼接。

## （三）Vue3 相关

### 1. RBAC + 组件封装提升复用率

1. RBAC：用户绑定角色，角色绑定权限，统一权限逻辑；
2. 封装通用组件：订单卡片、点赞评论模块，多页面复用；
3. 抽离接口请求函数到独立 js 文件，多处引入调用，消除重复代码。

### 2. Vue 响应式 + Map 优化

1. 响应式：ref 处理基本类型，reactive 处理对象 / 数组，数据劫持依赖收集；
2. Map 查询复杂度 O (1)，数组 find 循环查找 O (n)，大批量数据勾选、筛选性能更好。

### 3. computed

计算属性，有缓存；依赖不变不会重复执行，适合复杂数据计算。

## （四）性能优化

### 1. 首屏优化核心方案

1. 骨架屏：接口未返回数据时占位，消除白屏；
2. 图片懒加载：仅加载可视区域图片，节省流量；
3. 分包、减少首屏冗余资源。

### 2. 页面卡顿排查思路

1. Network 查看接口请求耗时、大资源加载；
2. 图片未懒加载、一次性渲染大量 DOM；
3. 频繁渲染无缓存，用 computed、防抖节流优化；
4. 大数据列表分页 / 虚拟滚动。

## （五）轮询 & WebSocket

### 1. 短轮询选型原因

1. 聊天交互低频，5s 延迟业务可接受；
2. WebSocket 需后端维护长连接，并发高服务器压力大；
3. 短轮询实现简单、改造成本低；增量拉取仅返回新增消息减少流量。

### 2. WebSocket 与 HTTP 区别

1. WebSocket：TCP 长连接，双向实时推送，一次握手持续通信；
2. HTTP：短连接，一问一答，请求完成立刻断开，只能客户端主动发起。

## （六）SQL 数据库

### 1. 疾病 + 药品关联查询 SQL 核心

1. 多表联查：疾病表左关联疾病药品中间表、药品表；
2. GROUP BY 疾病 ID 统计药品数量；
3. ORDER BY 浏览量 DESC 降序排序。

### 2. 用户注销处理

1. 逻辑删除（推荐）：UPDATE user SET is_delete=1 WHERE id=xxx；保留数据便于追溯；
2. 物理删除：DELETE FROM user WHERE id=xxx；数据彻底丢失。
