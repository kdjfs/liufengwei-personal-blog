# 二、各问题精简标准答案（核心要点）

## （一）项目权限相关

### 1. 权限信息 localStorage 持久化

核心：登录后把角色、token 存入 localStorage，页面初始化读取；localStorage 永久存储，关闭页面不丢失。

### 2. 菜单级权限控制

1. 路由守卫前置拦截，未登录跳转登录页；
2. 登录后读取角色，v-if 控制菜单渲染；
3. 手动输入无权限 URL，路由校验角色不匹配，强制拦截跳转。

### 3. 路由拦截、菜单区分

- 有全局路由守卫，先校验登录态；
- 菜单采用 v-if 判断角色渲染，未做后端动态路由注册。

### 4. URL 直接访问无权限页面拦截

路由守卫中获取当前用户角色，匹配页面所需权限，不匹配直接退回首页 / 登录页。

### 5. 按钮级权限实现

同样 v-if 绑定角色字段，不同角色展示 / 隐藏对应操作按钮。

### 6. 大量 v-if 冗余优化、无 v-if 按钮权限方案

1. 优化方案 1：**自定义权限指令 v-permission**，传入权限标识统一判断，消除页面大量 v-if；
2. 优化方案 2：后端返回当前角色权限列表，页面判断权限数组是否包含按钮权限；
3. 优化方案 3：动态生成按钮组件，过滤无权限操作项。

## （二）智慧生猪监控项目

### 1. 实时监控数据实现

ECharts 渲染图表展示传感器数据。

### 2. 轮询 vs WebSocket

- 项目使用轮询；
- 轮询：客户端定时主动发请求，服务端压力大，实时性差；
- WebSocket：长连接，服务端主动推送，毫秒级实时，适合监控场景。

### 3. 大数据量图表优化

1. 数据预处理过滤无用字段，减少循环开销；
2. 图表防抖，滚动 / 窗口缩放不重复重绘；
3. 数据分片渲染，不一次性渲染全部点位。

### 4. 小程序分包 + 懒加载优化

1. 分包：app.json 配置 subPackages，非核心页面分包，减小主包体积；
2. 骨架屏：接口未返回数据前展示占位骨架；
3. 图片懒加载：仅渲染可视区域图片。

### 5. 判断元素进入可视区域 API

标准 API：**IntersectionObserver**；

备选方案：滚动监听 scroll 事件，结合 getBoundingClientRect 手动计算视口交叉。

## （三）JS Promise

### 1. Promise 介绍

1. 解决回调地狱，三种状态：pending、fulfilled、rejected；
2. .then 处理成功、.catch 捕获异常；
3. async/await 是语法糖，同步写法写异步，搭配 try/catch 捕获错误。

### 2. try/catch 能否捕获 Promise 内部报错

**不能**

原因：Promise 内部错误属于微任务，同步 try 只能捕获同步代码异常；async 函数内 await Promise 报错才可被外层 try 捕获，普通同步代码块中 new Promise 报错无法捕获。

## （四）浏览器缓存

### 1. 强缓存

不请求服务器，直接读取本地缓存文件；依靠 Cache-Control、Expires 控制有效期。

### 2. 强缓存状态码

200 OK (from disk cache / from memory cache)

### 3. 浏览器缓存存储位置

内存缓存 (memory cache)、磁盘缓存 (disk cache)、Service Worker 缓存、HTTP 缓存、localStorage/sessionStorage（业务手动缓存）。

## （五）Vue3 基础

### 1. Vue2/Vue3 使用情况

熟练 Vue3；Vue2 仅学习未上线开发项目。

### 2. v-if 和 v-show 能否同用、区别

1. 不建议同一 DOM 同时使用；
2. v-if：条件为 false 直接销毁 DOM，切换开销大；
3. v-show：仅 CSS display:none 隐藏，DOM 保留，频繁切换推荐。

### 3. == 和 === ；null == undefined

- === 严格相等：同时判断**值 + 数据类型**；
- == 宽松相等：自动隐式类型转换后再比较；
- `null == undefined` 结果为 true，规范规定两者相等，`null === undefined`为 false。

## （六）CSS 布局

### 1. flex 主轴副轴、flex 居中

1. 默认 flex-direction: row，主轴水平，justify-content 控制主轴对齐，align-items 控制交叉轴垂直；
2. flex-direction: column 时主轴垂直，justify-content 控制垂直方向。

### 2. 绝对定位 50% 偏移修正方案

top:50%; left:50%; transform: translate (-50%, -50%);

translate 百分比基于元素自身宽高偏移，抵消父级 50% 偏移，实现完全居中。

### 3. 滚动到指定位置固定顶部

1. JS 方案：监听 scroll，判断元素 offsetTop，达到阈值添加 fixed 类；
2. 纯 CSS 方案：position: sticky，设置 top:0，父容器不能有 overflow:hidden。

## （七）防抖节流

### 1. 使用场景

- 防抖：搜索输入联想、窗口 resize；停止操作延迟执行一次；
- 节流：滚动监听、按钮频繁点击、拖拽；固定间隔执行一次。

### 2. 高频点击节流执行次数与原理

1 秒点击 100 次，节流只执行设定间隔内 1 次；

实现：设置时间戳 / 定时器，未到间隔直接拦截函数执行。

## （八）小程序多文件上传

1. 小程序支持 FormData 多文件上传，但原生上传组件一次单文件；
2. 单个 FormData 请求可携带多个 file 字段实现批量上传；
3. 多文件常用方案：Promise.all 并发多个上传请求。

## （九）候选人反问问题面试官解答

1. 绝对定位居中：top/left50% + transform: translate (-50%,-50%)；
2. 实习重点：JS、CSS 前端基础 > 项目经验，推荐《JavaScript 高级程序设计（红宝书）》夯实 JS，Vue 框架重点学习。
